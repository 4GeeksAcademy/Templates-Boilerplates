## 🎯 Schemas Incluidos

### 1. **Organization Schema** 📋
Información principal de la empresa
```json
{
  "name": "TrackFlow",
  "foundingDate": "2009",
  "numberOfEmployees": 130,
  "areaServed": ["US", "Spain"]
}
```
**Beneficio:** Google Knowledge Graph con logo, descripción y ubicaciones

### 2. **Address Schema** 📍
Ubicaciones físicas (Los Ángeles + Zaragoza)
```json
{
  "addressCountry": "US/ES",
  "addressLocality": "Los Angeles/Zaragoza",
  "telephone": "+1-213-555-0147 / +34-976-555-0147",
  "email": "sales/ventas@trackflow.com"
}
```
**Beneficio:** Aparece en Google Maps y búsquedas locales

### 3. **Service Schema** 🔧
Cuatro servicios oferecidos
- Warehouse Management
- Last-Mile Delivery
- Reverse Logistics
- Visibility & Tracking

**Beneficio:** Servicios aparecen en búsquedas específicas

### 4. **ContactPoint Schema** 📞
Puntos de contacto por región
- US: +1-213-555-0147 (English)
- ES: +34-976-555-0147 (Español)

**Beneficio:** Información de contacto clara en resultados

### 5. **FAQPage Schema** ❓
4 preguntas frecuentes estructuradas

**Beneficio:** Google muestra FAQ en "Featured Snippets"

### 6. **BreadcrumbList Schema** 🔗
Navegación: Home → Services → Coverage → Contact

**Beneficio:** Breadcrumbs aparecen en SERP

### 7. **WebPage Schema** 📄
Información de la página
- Título y descripción
- Fecha de publicación/modificación
- Imagen destacada

**Beneficio:** Mejor comprensión del contenido

### 8. **AggregateRating Schema** ⭐
Calificación promedio: 4.8/5 (150 reseñas)

**Beneficio:** Estrellas en SERP

## 🚀 Validación

### Herramientas Recomendadas
1. **Google Structured Data Testing Tool**
   - https://search.google.com/structured-data/testing-tool

2. **Rich Results Test**
   - https://search.google.com/test/rich-results

3. **Schema.org Validator**
   - https://validator.schema.org/

### Verificación Local
```bash
# Contar JSON-LD scripts
grep -c 'application/ld+json' index.html

# Ver tipos de schema
grep '@type' index.html | sort | uniq -c

# Validar JSON
python -m json.tool < index.html
```
