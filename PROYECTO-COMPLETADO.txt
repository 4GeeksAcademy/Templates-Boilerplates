💡 SOPORTE Y AYUDA
═══════════════════════════════════════════════════════════════════════════

Problema: Servidor no inicia
  → Solución: Verificar puerto 3000 no esté en uso
  → Comando: lsof -i :3000

Problema: Traducción no funciona
  → Solución: Limpiar localStorage
  → Comando: localStorage.clear() (en consola)

Problema: Formulario no valida
  → Solución: Revisar consola (F12) por errores
  → Verificar JavaScript está habilitado

Problema: Responsive no funciona
  → Solución: Limpiar cache (Ctrl+Shift+R)
  → Verificar DevTools en responsive mode
