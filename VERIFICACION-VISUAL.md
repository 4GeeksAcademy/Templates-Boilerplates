## 📊 Validación de Formulario

### Campo Requerido (Nombre)
```
1. Intenta enviar sin nombre
   ✅ Se muestra error en rojo: "Name is required"
   ✅ Campo tiene border rojo
   ✅ Mensaje desaparece cuando escribes
   
2. Llena campo
   ✅ Error desaparece
   ✅ Se ve validación OK
```

### Campo Email
```
1. Escribe: "correo-invalido"
   ✅ Error: "Please enter a valid email"
   ✅ Campo rojo
   
2. Escribe: "correo@dominio.com"
   ✅ Error desaparece
   ✅ Validación OK
```

### Checkbox Términos
```
1. Intenta enviar sin checkbox
   ✅ Error: "You must accept the terms"
   
2. Marca checkbox
   ✅ Error desaparece
   ✅ Puedes enviar
```
