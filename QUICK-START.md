# 🚀 QUICK START - Acceso a la Landing Page Pública

## ⚡ En 5 Pasos

### 1️⃣ Abre el Panel de Puertos
- Mira **abajo a la derecha** de VS Code
- Verás un tab llamado **"PORTS"**
- Si no lo ves: `Ctrl+Shift+P` → escribe "Ports: Focus on Ports View"

### 2️⃣ Localiza Puerto 8000
Deberías ver:
```
8000    Python HTTP Server    [Active]
```

### 3️⃣ Configura como Público
- **Clic derecho** en el puerto 8000
- Selecciona **"Port Visibility"**
- Elige **"Public"**

### 4️⃣ Copia la URL
Se generará automáticamente una URL como:
```
https://[codespace-name]-8000.preview.app.github.dev/
```

### 5️⃣ Abre en Navegador
Copia y pega la URL en tu navegador. ¡Listo! 🎉

## 🔍 Validación Rápida

### En DevTools (F12)
1. **Console:** Debe estar limpia (sin errores rojos)
2. **Network:** Todos los recursos deben cargar (200 OK)
3. **Lighthouse:** Click en "Analyze page load" → Accessibility score 90+

### Con Google
1. Ir a: https://search.google.com/test/rich-results
2. Pegar tu URL pública
3. Debe decir: "Passed the test" ✅

## ❓ Problemas?

### URL no funciona
- [ ] Puerto está en "Public"? Verifica paso 3
- [ ] Esperaste 5-10 segundos? La propagación toma tiempo
- [ ] Intenta limpiar cache: `Ctrl+Shift+Del`

### Página se ve rota
- [ ] Abre DevTools (F12)
- [ ] Revisa Console para errores
- [ ] Tab Network → revisa qué no cargó
- [ ] Recarga: `Ctrl+R`

### No veo el panel de Puertos
- [ ] `Ctrl+Shift+P` → "Ports: Focus on Ports View"
- [ ] O mira muy abajo en VS Code
